# CT3Tweaks
A GUI (and command-line) tool for modifying Crazy Taxi 3 to support
custom resolutions, higher framerate and higher field of view.

> [!WARNING]
> CT3Tweaks is end-of-life and will not be updated.  
> It has been replaced by **[taxipatch]**, which includes the same patches CT3Tweaks does, and more.


[taxipatch]: https://github.com/stashymane/taxipatch
